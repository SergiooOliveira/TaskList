# Wishlist App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal, cloud-synced wishlist web app. You paste a product link, it fetches the picture, name and price, and you can check for price drops, mark items bought and filter by Bought / Not bought.

**Architecture:** A single-page app (Vite + React + TypeScript) served as static files from GitHub Pages. It talks to Supabase for login (email magic link), the `items` table (with row-level security) and one Edge Function, `fetch-product`, which downloads store pages server-side and parses them. The HTML parser is a plain TS module with no Deno imports, so Vitest can test it.

**Tech Stack:** Vite, React 18, TypeScript, `@supabase/supabase-js` v2, Vitest + @testing-library/react + jsdom, Supabase Edge Functions (Deno), GitHub Actions → GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-24-wishlist-design.md` (look: `docs/superpowers/specs/2026-11-24-wishlist-look.html`)

## Global Constraints

- Palette Emerald Night, dark only: bg `#0F1D17`, surface `#18302A`, text `#E6F2EA`, muted `#86A898`, accent `#4FB287`, highlight `#21463A`, sale `#9FE0B8`.
- Fonts: Space Grotesk (headings), Inter (text), from Google Fonts with system-ui fallback.
- All animation stops under `prefers-reduced-motion: reduce`.
- Currency is EUR only. Prices are stored as integer cents and displayed as `€299,99` (pt-PT format).
- The browser never fetches store pages. Only `fetch-product` does.
- Nothing secret is committed. Only `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` reach the client. `.env` is gitignored.
- Vite `base` is `/TaskList/`.
- Failing to fetch a product never blocks saving it.

## Review Focus

1. **Prices with thousands separators** (`"1.299,99"`, `"1,299.99"`, `1299.99`) must all parse to `129999`. Tested in Task 2.
2. **Store blocks the request** (403, captcha page, timeout): `fetch-product` returns `{}` with status 200, and the add form opens empty and editable. Tested in Tasks 2 and 3.
3. **A price check finds a higher or missing price**: no false drop badge. A higher price clears `previous_price_cents`, and a missing one changes nothing. Tested in Task 5.
4. **A link pasted without a scheme** (`worten.pt/p/123`) gets `https://` prepended. A non-http(s) scheme (`javascript:`, `file:`) is rejected. Tested in Task 3.
5. **The image fails to load** (hotlink blocked, or `image_url` empty): the row shows the placeholder thumb, never a broken-image icon. Tested in Task 5.

### Task 5: The list, filter, bought toggle and price display

**Files:**
- Create: `src/lib/items.ts`, `src/lib/items.test.ts`, `src/components/Wishlist.tsx`, `src/components/ItemRow.tsx`, `src/components/ItemRow.test.tsx`

**Interfaces:**
- Consumes: `supabase` (Task 4).
- Produces, in `src/lib/items.ts`:
  - `export type Item` mirroring the table's columns exactly, in snake_case as the DB returns them (no mapping).
  - `listItems(): Promise<Item[]>` ordered by `created_at desc`. `addItem(p: Pick<Item,'url'|'title'|'image_url'|'store'|'price_cents'>): Promise<Item>`. `updateItem(id: string, patch: Partial<Item>): Promise<Item>`. `deleteItem(id: string): Promise<void>`. Each one throws on a Supabase error.
  - `applyPriceCheck(item: Item, newCents: number | undefined): Partial<Item> | null`. The rule is:
    - `undefined` → `null` (no change)
    - `newCents < price_cents` → `{ price_cents: newCents, previous_price_cents: item.price_cents }`
    - `newCents > price_cents` → `{ price_cents: newCents, previous_price_cents: null }`
    - equal → `{}`
    - `price_cents` null → `{ price_cents: newCents }`
    - every non-null result also sets `price_checked_at` to now.
  - `dropPercent(prev: number, cur: number): number` returns `Math.round((1 - cur/prev) * 100)`.
  - `formatEuro(cents: number): string` uses `Intl.NumberFormat('pt-PT', {style:'currency', currency:'EUR'})`.

- [ ] **Step 1: Write the failing tests** `items.test.ts`:

expect(applyPriceCheck({ ...base, previous_price_cents: 40000 }, 39999)).toMatchObject({ price_cents: 39999, previous_price_cents: null });
expect(applyPriceCheck(base, 37999)).not.toHaveProperty('previous_price_cents');
expect(applyPriceCheck({ ...base, price_cents: null }, 1000)).toMatchObject({ price_cents: 1000 });
